# Support

Use [GitHub Issues](https://github.com/faustbrian/go-fault-injection/issues/new)
for reproducible defects, documentation gaps, and bounded feature proposals.
Include the module path and version, Go version, platform, minimal reproduction,
expected behavior, actual behavior, and relevant non-secret logs.

Use [GitHub Discussions](https://github.com/faustbrian/go-fault-injection/discussions)
for adoption questions and bounded design exploration. Use the private process
in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

Support covers the latest release in the latest published stable major series
according to [`COMPATIBILITY.md`](COMPATIBILITY.md). A new stable major
supersedes the previous major at publication. The published series is currently
v1; the pending v2 source is not a published release. Older releases,
superseded major series, and the `main` branch are unsupported; upgrade before
opening a request. See [`SECURITY.md`](SECURITY.md) for the v2 support cutover
and migration requirements.
